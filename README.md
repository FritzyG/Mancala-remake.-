Mancala Remake
A Java implementation of the classic Mancala board game developed using Object-Oriented Programming (OOP) principles and Java Swing.

Project Overview
This project recreates the traditional Mancala game with a graphical user interface and fully implemented gameplay mechanics. The application was designed with a modular object-oriented architecture to separate game logic, player interactions, board management, and user interface components.

The project demonstrates software engineering concepts including object-oriented design, event-driven programming, GUI development, and application state management.

Features
Interactive Java Swing graphical user interface
Complete Mancala gameplay implementation
Turn-based game management
Score tracking and winner determination
Custom board and pit management
Object-oriented class hierarchy
Real-time game state updates
Modular and maintainable code structure
Technologies Used
Java
Java Swing
Object-Oriented Programming (OOP)
Project Structure
Board.java          -> Board state and game management
Game.java           -> Core game logic
HumanPlayer.java    -> Human player implementation
Player.java         -> Player abstraction
Pit.java            -> Pit structure definition
pitImpl.java        -> Pit implementation
MancalaGUI.java     -> Swing graphical interface
Main.java           -> Application entry point
